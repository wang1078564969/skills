# G6 3D 开发

本文件是 skill 对官方 3D 文档的整合版，汇总自 `manual/further-reading/3d`、`backup/CameraSetting`、`manual/layout/D3Force3DLayout`。3D 能力不在 `@antv/g6` 主包中，由官方扩展包 **`@antv/g6-extension-3d`** 提供（G6 5.0 新增，见 `manual/whats-new/feature`）。

## 安装

```bash
npm install @antv/g6-extension-3d --save
```

## 扩展包导出一览

| 类别 | 导出 | 说明 |
|---|---|---|
| 渲染器 | `renderer` | 3D 渲染器；**无需注册**，创建 Graph 时直接传入 `renderer` 配置项 |
| 节点 | `Capsule` | 胶囊 |
| 节点 | `Cone` | 圆锥 |
| 节点 | `Cube` | 立方体 |
| 节点 | `Cylinder` | 圆柱 |
| 节点 | `Sphere` | 球体 |
| 节点 | `Torus` | 圆环 |
| 边 | `Line3D` | 3D 线 |
| 布局 | `D3Force3DLayout` | 3D 力导向布局，`type: 'd3-force-3d'` |
| 交互 | `DragCanvas3D` / `ObserveCanvas3D` / `RollCanvas3D` / `ZoomCanvas3D` | 拖拽 / 观察 / 旋转 / 缩放画布（官方文档仅列出名称，未给出更多配置项，不要编造） |
| 插件 | `Light` | 光源 |

**创建 3D 图必备**：renderer + 至少一个 3D 节点 + `Line3D` + `Light`。

## 注册

元素、边、插件按类别注册；renderer 不注册，直接传给 Graph：

```ts
import { register, ExtensionCategory } from '@antv/g6';
import { Sphere, Line3D, Light } from '@antv/g6-extension-3d';

register(ExtensionCategory.NODE, 'sphere', Sphere);
register(ExtensionCategory.EDGE, 'line3d', Line3D);
register(ExtensionCategory.PLUGIN, 'light', Light);
```

## 创建 3D 图

```ts
import { Graph } from '@antv/g6';
import { renderer } from '@antv/g6-extension-3d';

const graph = new Graph({
  // ... 其他配置
  renderer, // 使用 3D 渲染器（直接传实例，不是 type 字符串）
  node: {
    type: 'sphere',
    style: {
      materialType: 'phong', // Phong 材质
    },
  },
  edge: {
    type: 'line3d',
  },
  plugins: [
    {
      type: 'light',
      directional: {
        // 方向光
        direction: [0, 0, 1],
      },
    },
  ],
});

graph.render();
```

`Light` 光源目前官方文档只给出 `directional`（方向光）的 `direction: [x, y, z]` 配置示例，未列出其他光源类型或配置项——文档没有的不要编造。

## CameraSetting 相机插件

配置 3D 场景相机。官方文档说明 `@antv/g6` 已内置注册该插件，一般直接在 `plugins` 中使用 `type: 'camera-setting'` 即可；若运行时报未注册，手动注册（`CameraSetting` 从 `@antv/g6` 导入）：

```ts
import { register, CameraSetting, ExtensionCategory } from '@antv/g6';
register(ExtensionCategory.PLUGIN, 'camera-setting', CameraSetting);
```

```ts
{
  plugins: [
    {
      type: 'camera-setting',
      projectionMode: 'perspective',
      near: 0.1,
      far: 1000,
      fov: 45,
      aspect: 1,
    },
  ],
}
```

⚠️ 仅在 3D 场景下使用。配置项全集：

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | `'camera-setting'` | — | 必填 |
| `projectionMode` | `'perspective'` \| `'orthographic'` | — | 投影模式；透视投影仅 3D 场景有效 |
| `cameraType` | `'orbiting'` \| `'exploring'` \| `'tracking'` | — | `orbiting` 固定视点移动相机；`exploring` 类似且允许在南北极间旋转；`tracking` 固定相机改变视点 |
| `near` | number | — | 近平面位置 |
| `far` | number | — | 远平面位置 |
| `fov` | number | — | 视角，仅透视相机有效 |
| `aspect` | number \| `'auto'` | — | 视口宽高比，仅透视相机有效；`'auto'` 跟随画布 |
| `distance` | number | `500` | 相机到目标的距离 |
| `minDistance` / `maxDistance` | number | — | 最小 / 最大视距 |
| `azimuth` | number | — | 方位角 |
| `elevation` | number | — | 仰角 |
| `roll` | number | — | 滚转角 |

## D3Force3DLayout 布局

`type: 'd3-force-3d'`，d3-force 的三维扩展：在 X/Y/Z 三维空间模拟中心力、碰撞力、链接力、多体力、径向力、坐标力。

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | string | `d3-force-3d` | 必填 |
| `numDimensions` | number | `3` | 固定为 3 |
| `nodeSize` | number \| 函数 | `10` | 节点直径，用于碰撞检测 |
| `iterations` | number | — | 迭代次数，越大越精确但越慢 |
| `alpha` / `alphaDecay` / `alphaMin` / `alphaTarget` / `velocityDecay` | number | `1` / `0.028` / `0.001` / `0` / `0.4` | 迭代收敛控制 |
| `center` | `{ x, y, z, strength }` | 中心 `(0,0,0)`，强度 `1` | 中心力 |
| `collide` | `{ radius, strength, iterations }` | `10` / `1` / `1` | 碰撞力 |
| `link` | `{ distance, strength, iterations, id }` | `30` / `1` / `1` | 链接力 |
| `manyBody` | `{ strength, theta, distanceMin, distanceMax }` | `-30` / `0.9` / `1` / `Infinity` | 多体力 |
| `radial` | `{ radius, strength, x, y, z }` | `100` / `0.1` / `0` | 径向力（吸附到球面） |
| `x` / `y` / `z` | `{ strength, x\|y\|z }` | — | 各轴坐标力 |
| `onTick` | 回调 | — | 每次迭代回调 |

完整的函数签名与更多说明见 `manual/layout/D3Force3DLayout.zh.md`。
